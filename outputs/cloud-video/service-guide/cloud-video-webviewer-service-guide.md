## 2. 추진 배경

`confirmed` (슬라이드 01·02)

- 국내 영상보안 시장은 CAGR 9.3% 성장 중이나, 에스원 성장률은 '21년 10%→ '25년 6.5%로 하락 추세 → 실질 시장 지배력 위축
- 기존 라인업: 대·중·소형은 SVMS·NVR로 대응하나, **SOHO(1~4인) 대응 상품 부족** (침투율 38.7%)
- 현 판매 중인 클라우드 CCTV는 LGU+ 서버 위탁 운영 → 판매 가능 수량 한정, 단순 저장/조회 서비스만 제공하여 경쟁 열위
- 글로벌 영상 보안 시장: 17%, CAGR 5.2% 성장 중 — Full 서비스 밸류체인 확보로 경쟁우위 회복 필요

## 4. 서비스 전환 모델 — As-Is vs To-Be

`confirmed` (슬라이드 06)

| 구분 | As-Is · 로컬 기기(렌탈) 중심 | To-Be · 영상 Full 서비스 모델 |
|------|------------------------------|-------------------------------|
| **운영 주체** | 고객이 직접 영상 모니터링 및 대응 | 에스원이 클라우드로 모니터링·대응 통합 제공 |
| **구성** | 영상기기(렌탈/구매) → 모니터 → 고객 | 영상기기(렌탈) → 클라우드 영상 시스템 → 고객 |
| **부가 서비스** | 없음 | AI 분석, AI 관제, 원격 A/S, 출동 |
| **제공 서비스** | 기기 렌탈 + A/S만 | 기기 렌탈 + 센싱·모니터링·대응 (고객 선택) |

> 통합 영상 모니터링 서비스와 AI 영상분석 기반의 차별화된 맞춤형 안심 서비스 제공

## 5. 상품 개념 — 3가지 구성 요소

`confirmed` (슬라이드 05)

### ① 클라우드用 AI 카메라

| 항목 | 내용 |
|------|------|
| 유형 | 돔형(실내), 블릿형(실외) |
| 기본 AI 기능 | 침입, 배회, 화재 등 — 에스원 자체 AI 알고리즘 적용 |
| 추가 AI 기능 | 라인크로스, 피플카운트 탑재 |
| 전송 | 실시간영상 전송, 이벤트영상 전송 |
| 규격 | 2MP, H.265, 클라우드 전용 |

### ② 클라우드 S/W (웹뷰어)

| 기능 | 설명 |
|------|------|
| 영상 저장 | 클라우드 기반 영상 저장 |
| 장비이상감지 | 카메라·장비 이상 상태 감지 |
| 영상 모니터링 | 실시간 영상 모니터링 |
| 녹화영상 전송 | 저장된 녹화영상 조회 및 전송 |
| 영상 검색 (문장 검색 포함) | 자연어 문장으로 영상 구간 검색<br>예: "파란선초 및 빨간색모자를 쓴 사람" → 해당 영상 검색 |
| 솔루션 연동 | 주요 시스템과 연동 |
| AI 알고리즘 구독 | 침입·문장검색 외 유료 옵션으로 추가 |

### ③ 기존 시스템 연동

| 시스템 | 역할 |
|--------|------|
| 통합계정 | 에스원 계정 통합 관리 |
| 관제서버 | 요청 출동 및 영상확인 관제 |
| 모두App | 고객용 모바일 서비스 |

## 10. 확인 필요 항목

> 기획문서에 언급됐으나 상세 정의가 없거나 웹뷰어 설계 시 결정이 필요한 항목

1. **웹뷰어(클라우드 S/W) 화면 구성** — 기획문서에는 기능 목록만 있고 화면 구조·흐름 미정의
2. **웹뷰어 접근 주체** — 기획문서에서 모두App(고객)과 구분되나, 웹뷰어(클라우드 S/W)를 에스원 내부 직원이 사용하는지 고객도 접속하는지 불명확
3. **에스원 내부 운영자 역할 체계** — 기획문서에 역할 구분 언급 없음 (모니터요원·운영자 등 체계 미정의)
4. **통합계정 연동 방식** — 기능 명시만 있고 인증 방식(SSO 등) 미정의
5. **관제서버 연동 및 요청출동 처리 흐름** — 월 2회 기본 제공은 확인됨, 웹뷰어 내 처리 상세 흐름 미정의
6. **모두App과 클라우드 S/W의 기능 경계** — 어떤 기능은 App에서만, 어떤 기능은 웹에서만 제공하는지 미정의
7. **영상검색 화면 구성** — 문장 검색 기능은 확인됨, 검색 결과 표시 방식·UX 미정의
8. **AI 알고리즘 유료 옵션 관리 화면** — 구독 추가 구매 흐름·화면 위치 미정의

## 11. UX 설계 시 참고할 수 있는 기획 단서

`confirmed` (슬라이드 기준)

- 고객 서비스 방향: "고객이 원하는 서비스 선택 제공" — 선택적 구독 옵션을 UI에서도 명확히 구분해야 함
- 출동 서비스는 기본에 포함(월 2회)되어 있으며 옵션으로 영상확인 관제 추가 가능 — 서비스 티어 구분 UX 필요
- 판매 채널이 다이렉트몰 중심 → 셀프 온보딩·카메라 등록 흐름이 중요할 수 있음
- 타깃인 SOHO는 보안 전문인력 없는 소규모 사업장 → 복잡한 설정보다 자동화·단순화 우선
- 모두App(고객 모바일)과 클라우드 S/W(웹뷰어)를 구분 설계 — 각 채널의 역할과 기능 범위 협의 필요
