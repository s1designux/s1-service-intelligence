# 클라우드영상시스템 PC 웹뷰어 — IA 제안

> **역할:** ia-designer  
> **작성일:** 2026-05-21  
> **기반:** 기획안(Figma 10장) + Verkada 벤치마크 + 사양 우선순위표

---

## 전제 조건

이 IA는 **웹뷰어 접근 주체(A-01)가 미확정**인 상태에서 작성됐다.  
에스원 내부 관제 직원이 주 사용자라는 전제로 설계하되,  
고객(SOHO 사업자)이 접근할 경우에도 기본 기능을 제공할 수 있는 구조를 유지한다.

---

## A. 최소 출시 IA

> Phase 1 출시에 적합한 가장 단순한 구조.  
> 사용자가 바로 영상 조회·검색·이벤트 처리를 할 수 있는 수준.

```
클라우드영상시스템 PC 웹뷰어 (최소 출시)
│
├─ 대시보드
│  └─ 사이트별 카메라 상태 요약 (온라인/오프라인/이벤트 수)
│
├─ 실시간 영상
│  ├─ 멀티 카메라 그리드 (2x2 / 3x3)
│  └─ 단일 카메라 상세 보기
│
├─ 이벤트
│  ├─ 이상감지 이벤트 목록
│  └─ 출동 요청 처리
│
├─ 영상 검색
│  ├─ AI 문장 검색
│  ├─ 날짜·카메라 필터
│  └─ 검색 결과 영상 클립 보기
│
├─ 카메라 관리
│  ├─ 카메라 목록·상태
│  └─ 카메라 기본 설정 (이름, AI 알고리즘)
│
└─ 설정
   ├─ 내 계정 (통합계정 연동)
   └─ AI 구독 옵션 관리
```

**최소 출시 IA 특징:**
- 6개 대메뉴 / 하위 화면 12개
- 기획 명시 6개 기능 100% 커버
- 핵심 시나리오 4개 모두 완수 가능
- 인물·차량·분석·플로어 플랜 제외

## B. 권장 IA

> 초기 사용성과 향후 확장성을 함께 고려한 추천 구조.  
> Phase 1에 포함하면 좋은 P1 사양까지 반영.

```
클라우드영상시스템 PC 웹뷰어 (권장)
│
├─ 대시보드
│  ├─ 운영 현황 요약 (카메라 총수, 온라인/오프라인, 이벤트 수)
│  ├─ 사이트별 상태 카드 (각 고객사 카메라 현황)
│  └─ 최근 이벤트 요약 (최근 24h 이상감지 목록)
│
├─ 실시간 영상
│  ├─ 멀티 카메라 그리드 (2x2 / 3x3 / 4x3)
│  │  └─ 얼굴 블러 토글
│  ├─ 단일 카메라 상세 보기
│  └─ [향후] 레이아웃 저장·편집
│
├─ 녹화 영상
│  ├─ 24h 타임라인 재생 (1x / 2x / 4x)
│  ├─ 날짜·카메라 선택
│  ├─ 스냅샷 캡처
│  └─ 영상 다운로드
│
├─ AI 영상 검색
│  ├─ 자연어 문장 검색
│  ├─ 검색 필터 (사이트·카메라·날짜·감지 유형)
│  ├─ 최근 검색·추천 검색
│  └─ 검색 결과 클립 보기
│
├─ 이벤트 관리
│  ├─ 이벤트 수신함 (읽음·안읽음·음소거)
│  ├─ 이상감지 이벤트 상세 (영상 클립 포함)
│  ├─ 출동 요청 처리
│  ├─ 사건 이력 조회
│  └─ 기본 알림 규칙 설정
│
├─ 카메라 관리
│  ├─ 카메라 목록·장비 상태
│  ├─ 카메라 등록 (온보딩)
│  ├─ 카메라 기본 설정
│  │  ├─ 일반 (이름·위치·사이트)
│  │  ├─ AI 이벤트 (감지 유형 on/off)
│  │  └─ 프라이버시 (마스크 영역)
│  └─ 원격 펌웨어 업데이트
│
└─ 관리자
   ├─ 계정·로그인 (SSO 통합계정)
   ├─ 사용자·권한 관리
   ├─ AI 구독 옵션 관리
   ├─ 이상감지 빈도 통계 (기본 리포트)
   └─ 감사 로그
```

**권장 IA 특징:**
- 6개 대메뉴 / 하위 화면 23개
- P0 사양 100% + P1 사양 70% 커버
- 녹화 영상을 실시간 영상과 분리 → 탐색 편의성 향상
- 이벤트 관리를 독립 대메뉴로 분리 → 관제 업무 흐름 명확화

## C. 고도화 IA

> Verkada 수준으로 확장할 때 고려할 전체 구조.  
> Phase 2 이후 도입을 검토할 메뉴 포함.

```
클라우드영상시스템 PC 웹뷰어 (고도화)
│
├─ 대시보드 (권장 IA와 동일)
│
├─ 실시간 영상 (권장 IA + 레이아웃 저장)
│
├─ 녹화 영상 (권장 IA + 멀티캠 동기화 재생)
│
├─ AI 영상 검색 (권장 IA + 검색→알림 규칙 변환)
│
├─ 이벤트 관리
│  ├─ (권장 IA 전체)
│  ├─ 커스텀 알림 규칙 빌더 (조건 조합)
│  └─ 수사 케이스 관리
│
├─ 인물·차량 [Hold — 개보법 확인 후]
│  ├─ 인물 감지 목록 (얼굴 비식별 처리 방식 결정 후)
│  └─ 차량 번호판 인식 (LPR 사양 확인 후)
│
├─ 분석·통계
│  ├─ 이상감지 빈도 트렌드
│  ├─ 재실 인원 분석
│  └─ 대기열·동선 분석 [Phase 2]
│
├─ 플로어 플랜 [Phase 2]
│  └─ 평면도 기반 카메라 위치 보기
│
├─ 카메라 관리 (권장 IA + 장치 통계)
│
└─ 관리자
   ├─ (권장 IA 전체)
   ├─ 데이터 내보내기·컴플라이언스
   └─ API Keys·Webhook 관리 [Phase 2]
```

## 대메뉴별 제공 사양 상세

---

### 1. 대시보드

#### 화면 목적
에스원 관제 직원이 로그인 직후 전체 고객사 카메라 상태와  
최근 이상감지 이벤트를 한눈에 파악하는 운영 현황 화면.

#### 하위 화면
- 운영 현황 요약 카드 (전체 카메라 수·온라인·오프라인·이벤트)
- 사이트별 상태 카드 목록
- 최근 24h 이벤트 요약

#### 제공 사양
| 사양 | 설명 | 우선순위 | 판단 | 비고 |
|---|---|---|---|---|
| KPI 수치 카드 | 전체·온라인·오프라인·이벤트 수 | P0 | adapt | SOC 콘솔 개념을 에스원 관제 맥락으로 |
| 사이트별 상태 카드 | 고객사 이름·카메라 수·이벤트 수 | P0 | adapt | Verkada SOC Console 참고 |
| 최근 이벤트 목록 | 최근 24h 이상감지 이벤트 5~10건 | P0 | keep | - |
| 이상감지 빈도 차트 | 시간대별 알림 발생 통계 | P1 | add | Verkada Alert Trends 참고 |

#### 초기 버전 포함 여부: 포함 (P0 사양)

#### 확인 필요
- 사이트 단위 vs 고객사 단위 표시 방식 (A-01 확인 필요)

---

### 2. 실시간 영상

#### 화면 목적
계약 고객사 카메라의 실시간 영상을 멀티 그리드 또는 단일 화면으로 확인.  
이상감지 이벤트 발생 시 해당 카메라로 즉시 전환.

#### 하위 화면
- 멀티 카메라 그리드 (2x2 / 3x3 / 4x3)
- 단일 카메라 상세 보기

#### 제공 사양
| 사양 | 설명 | 우선순위 | 판단 | 비고 |
|---|---|---|---|---|
| 멀티 그리드 레이아웃 | 2x2 / 3x3 / 4x3 전환 | P0 | keep | Verkada Live Grid 참고 |
| 단일 카메라 라이브 | 개별 카메라 전체 화면 보기 | P0 | add | 기획에 묵시 포함 |
| 얼굴 블러 토글 | 원터치 얼굴 비식별화 | P0 | add | 개보법 대응 필수 |
| 카메라 상태 표시 | 온라인·오프라인·이벤트 인디케이터 | P0 | keep | - |
| 레이아웃 저장·편집 | 그리드 구성 저장 | P1 | defer | Phase 2 — 초기는 기본 레이아웃 |

#### 초기 버전 포함 여부: 포함 (P0 사양)

#### 확인 필요
- PTZ 제어 여부 (S1 AI 카메라 PTZ 탑재 확인 필요)
- 최대 동시 스트림 수 (기술 확인)

---

### 3. 녹화 영상

#### 화면 목적
특정 날짜·시간의 녹화 영상을 타임라인으로 탐색하고,  
필요한 구간을 확인·저장·전송.

#### 하위 화면
- 24h 타임라인 재생
- 날짜·카메라 선택
- 스냅샷·다운로드

#### 제공 사양
| 사양 | 설명 | 우선순위 | 판단 | 비고 |
|---|---|---|---|---|
| 24h 타임라인 스크럽 | 24시간 타임라인 드래그 탐색 | P0 | keep | Verkada Playback 참고 |
| 재생 속도 (1x/2x/4x) | 배속 재생 | P0 | keep | - |
| 날짜 선택 | 날짜 기반 녹화 탐색 | P0 | keep | - |
| HQ/SQ 화질 전환 | 네트워크 환경에 따른 화질 선택 | P0 | adapt | 에스원 스트리밍 사양 확인 후 |
| 스냅샷 캡처 | 특정 프레임 이미지 저장 | P1 | adapt | 저장 방식·포맷 확인 |
| 영상 다운로드 | 구간 지정 MP4 다운로드 | P1 | adapt | 다운로드 정책·보안 검토 |
| 멀티캠 동기화 재생 | 여러 카메라 동시 재생 | P2 | defer | Phase 2 |

#### 초기 버전 포함 여부: 포함 (P0 핵심 / P1 일부)

#### 확인 필요
- 보관 기간 기본 30일·최대 60일 (기획 명시) — 타임라인에서 보관 기간 표시 방식
- 다운로드 보안 정책 (내부 전용 vs 고객 허용)

### 4. AI 영상 검색

#### 화면 목적
자연어 문장으로 영상을 검색해 원하는 구간을 빠르게 찾는다.  
S1의 핵심 차별점이자 기획문서에 명시된 기능.

#### 하위 화면
- 검색 입력 + 필터
- 최근 검색·추천 검색
- 검색 결과 클립 보기

#### 제공 사양
| 사양 | 설명 | 우선순위 | 판단 | 비고 |
|---|---|---|---|---|
| 자연어 문장 검색 | "파란 선초 및 빨간색 모자" 입력 | P0 | keep | 기획 핵심 차별점 |
| 검색 필터 | 사이트·카메라·날짜·감지 유형 | P0 | add | 검색 정확도 향상 |
| 검색 결과 클립 | 썸네일 그리드 + 구간 재생 | P0 | keep | 검색 후 영상 확인 필수 |
| 최근 검색 이력 | 자주 쓰는 검색 목록 | P1 | add | 비전문 사용자 편의성 |
| 추천 검색 템플릿 | 공통 검색 패턴 제공 | P1 | add | SOHO 사용자 가이드 |
| 검색 → 알림 규칙 | 검색 조건을 알림 트리거로 저장 | P2 | defer | Phase 2 |

#### 초기 버전 포함 여부: 포함 (P0 필수)

#### 확인 필요
- AI 검색 엔진 사양 (자체 개발 vs 외부 API)
- 검색 가능 보관 기간 기준

### 5. 이벤트 관리

#### 화면 목적
AI가 감지한 이상 이벤트를 확인하고 처리한다.  
에스원 관제 업무의 핵심 — 이벤트 확인 → 출동 요청 → 결과 기록.

#### 하위 화면
- 이벤트 수신함
- 이벤트 상세 (영상 클립)
- 출동 요청 처리
- 사건 이력 조회
- 알림 규칙 설정

#### 제공 사양
| 사양 | 설명 | 우선순위 | 판단 | 비고 |
|---|---|---|---|---|
| 이벤트 수신함 | 읽음·안읽음·음소거 분류 | P0 | keep | Verkada Alert Inbox 참고 |
| 침입·화재·배회 이벤트 | 기본 AI 감지 이벤트 | P0 | keep | 기획 명시 |
| 이벤트 영상 클립 | 감지 전후 영상 자동 클립 | P0 | keep | - |
| 출동 요청 처리 | 관제서버 연동 요청출동 | P0 | keep | 기획 핵심 시나리오 |
| 라인크로스·피플카운트 이벤트 | 유료 옵션 AI 이벤트 | P0 | keep | 구독 활성화 시 표시 |
| 알림 음소거·스누즈 | 시간 지정 음소거 | P1 | add | 무인매장 야간 운영 |
| 기본 알림 규칙 설정 | 감지 유형·시간대 조건 | P1 | adapt | 기본 규칙, 커스텀은 Phase 2 |
| 사건 이력 조회 | 과거 이벤트·처리 결과 목록 | P1 | add | 출동 결과 기록 |
| 커스텀 알림 규칙 빌더 | 복합 조건 알림 | P2 | defer | Phase 2 |
| 수사 케이스 관리 | 사건 클립 수집·타임라인 | P2 | defer | Phase 2 |

#### 초기 버전 포함 여부: 포함 (P0 필수 / P1 일부)

#### 확인 필요
- 관제서버 연동 요청출동 처리 흐름 상세 (확인항목 C-01)
- 월 2회 기본 출동 초과 시 처리 방식
- 영상확인 관제서비스(유료 10円) 연동 방식

### 6. 카메라 관리

#### 화면 목적
카메라 장치를 등록하고, 상태를 모니터링하며, 설정을 관리한다.

#### 하위 화면
- 카메라 목록·장비 상태
- 카메라 등록 (온보딩)
- 카메라 설정

#### 제공 사양
| 사양 | 설명 | 우선순위 | 판단 | 비고 |
