## P0 — 초기 필수 사양 (Phase 1 출시 기준)

> 이 사양이 없으면 서비스가 동작하지 않거나, 핵심 사용 시나리오를 완수할 수 없다.

| 사양 | 판단 | 이유 |
|---|---|---|
| 라이브 그리드 (2x2 / 3x3 / 4x3) | keep | 기획 명시 / 관제 핵심 화면 |
| 단일 카메라 라이브 보기 | add | 개별 카메라 확인 필수 |
| 24h 재생 타임라인 | keep | 기획 명시 / 녹화영상 조회 핵심 |
| 날짜 선택 녹화 탐색 | keep | 녹화영상 전송 기능의 기본 |
| 얼굴 블러 토글 | add | 개보법 대응 필수 |
| 이상감지 이벤트 수신함 | keep | 관제 핵심 업무 흐름 |
| 침입·화재·배회 AI 감지 이벤트 | keep | 기획 기본 AI 알고리즘 |
| 이벤트 → 출동 요청 처리 흐름 | keep | 기획 핵심 시나리오 |
| 자연어 문장 검색 | keep | 기획 핵심 차별점 |
| 검색 필터 (카메라·날짜) | add | 검색 정확도 필수 |
| 검색 결과 클립 뷰어 | keep | 검색 후 영상 확인 핵심 |
| 사이트·카메라별 현황 대시보드 | adapt | SOC 콘솔 개념 → 에스원 관제 화면 재설계 |
| 카메라 목록 & 장비 상태 | keep | 장비이상감지 기획 명시 |
| 카메라 온보딩 (장치 등록) | add | 다이렉트몰 셀프 온보딩 핵심 |
| 카메라 기본 설정 (이름·AI on/off) | adapt | General·Events 탭 우선 |
| SSO / 통합계정 로그인 | keep | 기획 명시 (확인항목 C-02) |
| 역할·권한 관리 | adapt | 에스원 내부 역할 구분 (관제원·운영자·관리자) |
| AI 알고리즘 구독 옵션 관리 | adapt | 화재·배회·라인크로스·피플카운트 on/off |

## P1 — 초기 권장 사양 (Phase 1에 포함 권장)

> Phase 1에 없어도 서비스는 동작하지만, 사용자 경험과 운영 효율을 크게 높인다.

| 사양 | 판단 | 이유 |
|---|---|---|
| 영상 스냅샷·다운로드 | adapt | 공유 방식은 에스원 정책 기준으로 조정 |
| 알림 음소거·스누즈 | add | 무인매장 야간 운영 시 과잉 알림 방지 |
| 기본 알림 규칙 설정 | adapt | 감지 유형·시간대 기본 조건 제공, 커스텀은 Phase 2 |
| 모두App 푸시 + 이메일 알림 채널 | adapt | Slack 등 3rd party는 Phase 2 |
| 사건 이력 목록·조회 | add | 출동 결과 기록·이력 관리 |
| 최근 검색·추천 검색 | add | 비전문 SOHO 사용자 편의성 |
| 라인크로스·피플카운트 감지 (구독 옵션) | keep | 기획 유료 옵션 명시 |
| 원격 펌웨어 업데이트 | add | AI 알고리즘 업데이트 연계 |
| 이상감지 빈도 기본 통계 | add | 운영 리포트 최소 단위 |
| 감사 로그 | add | 운영 보안·개보법 대응 |

> Phase 1 안정화 후 고도화 단계에서 도입을 검토한다.

|---|---|---|
| 멀티캠 동기화 재생 | defer | SOHO 8대 이하 — 단일 재생으로 Phase 1 충분 |
| 평면도 기반 카메라 보기 | adapt | 단순화 버전으로 Phase 2 도입 |
| 재실 인원 트렌드 | defer | 무인매장 니즈 있으나 Phase 2 |
| 대기열 분석 | defer | 음식점·카페 SOHO — Phase 2 |
| 동선 히트맵 | defer | 개보법 비식별 방식 확인 후 |
| 수사 케이스 관리 | defer | 출동 결과 연계 고도화 |
| API Keys & Webhook | defer | 관제서버 연동 고도화 시 |
| 검색 → 알림 규칙 변환 | defer | 기본 알림 구성 후 Phase 2 |
| 데이터 내보내기·컴플라이언스 | add | 개보법 대응 — Phase 2 이전에 정책 확인 |
