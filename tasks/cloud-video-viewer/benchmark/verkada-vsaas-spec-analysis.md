## 1. Verkada 서비스 개요

Verkada는 클라우드 기반 물리 보안 통합 플랫폼으로,  
VSaaS에서 출발해 출입통제·인터폰·공기질·직장관리까지 확장한 풀스택 보안 플랫폼이다.

- **포지션:** 글로벌 VSaaS 시장 1위 (기업용 / 엔터프라이즈 중심)
- **특징:** 단일 클라우드 SW로 모든 물리 보안 기기 통합 관리
- **사용자:** 기업 보안 담당자(내부) + 관리자 + Verkada 운영자
- **PC 웹뷰어 사용자:** 에스원 내부 관제 직원과 유사한 역할의 보안 담당자

## 3. PC 웹뷰어 관점에서 의미 있는 핵심 사양

VSaaS PC 웹뷰어가 반드시 갖춰야 할 Verkada의 기본 사양:

1. **라이브 그리드** — 다중 카메라 실시간 모니터링의 기본 화면
2. **24h 타임라인 재생** — 녹화 영상 조회의 핵심 UX
3. **이상감지 알림 수신함** — 관제 업무 핵심 흐름
4. **AI 문장 검색** — S1의 기획 명시 차별점이자 Verkada에서도 주요 기능
5. **장치 상태 대시보드** — 운영자 첫 화면
6. **SOC 콘솔 (관제 운영)** — 에스원 내부 관제 직원 핵심 화면
7. **얼굴 블러** — 한국 개보법 대응 필수
