# 클라우드영상시스템 웹뷰어 — DS Gap 목록

> **문서 유형:** Draft  
> **작성일:** 2026-05-21  
> **분류 기준:** DS에 없는 것만 기록. 있는 것은 적용 계획서·후보 매핑표 참조.  
> **원칙:** 지금 당장 채울 수 없는 gap은 억지로 채우지 않는다. 없으면 gap으로 남긴다.

---

## 범례

| 우선순위 | 의미 |
|---------|------|
| `P1` | 핵심 화면에서 반드시 필요. 영상 도메인 고유 요소. |
| `P2` | 여러 화면에서 반복 사용. 없으면 불편하지만 임시 대응 가능. |
| `P3` | 선택 기능 또는 Edge case. 나중에 추가해도 무방. |

---

## 1. 색상 토큰 Gap

### 1-1. 영상 배경 전용 토큰

| 필요 토큰 | 용도 | 현재 DS 상태 | 우선순위 |
|----------|------|-------------|---------|
| `--color-video-bg` | 카메라 셀 영상 영역 배경 (#000 또는 gray-dark-0) | 없음 | `P1` |
| `--color-video-overlay` | 영상 위 그라디언트 오버레이 (rgba 기반) | `--color-overlay` 존재하나 영상 전용 단계 없음 | `P2` |
| `--color-video-label-bg` | 카메라 이름 오버레이 배경 (반투명 검정) | 없음 | `P2` |

**임시 대응:** `--color-overlay` 활용 + gray-dark-0 직접 참조 (semantic 채널 없이)  
**피드백 요청:** 영상 플레이어·카메라 셀 전용 semantic 토큰 그룹 신설 검토 요청

---

### 1-2. AI 이벤트 태그 색상

| 이벤트 유형 | 필요 색상 역할 | 현재 DS 상태 | 우선순위 |
|-----------|-------------|-------------|---------|
| 침입 (Intrusion) | badge-bg, badge-text | `--color-status-error` 계열로 매핑 가능하나 전용 토큰 없음 | `P1` |
| 화재 (Fire) | badge-bg, badge-text | `--color-status-warning` 계열 후보 | `P1` |
| 배회 (Loitering) | badge-bg, badge-text | 전용 없음 — yellow 팔레트 임시 참조 | `P2` |
| 라인크로스 (Line Cross) | badge-bg, badge-text | 전용 없음 | `P2` |
| 피플카운트 (People Count) | badge-bg, badge-text | 전용 없음 | `P3` |

**임시 대응:** status-error / warning / info 순환 매핑  
**피드백 요청:** AI 이벤트 카테고리별 색상 토큰 또는 semantic alias 정의 요청

---

### 1-3. 구독 티어 표시 색상

| 필요 토큰 | 용도 | 현재 DS 상태 | 우선순위 |
|----------|------|-------------|---------|
| `--color-tier-basic` | 기본 구독 배지 | 없음 | `P2` |
| `--color-tier-premium` | 유료 옵션 배지 | 없음 | `P2` |

**임시 대응:** gray / blue 팔레트 직접 참조  
**피드백 요청:** 구독 티어 UI 패턴 정의 시 함께 논의 필요

## 2. 레이아웃 / 스페이싱 토큰 Gap

| 필요 토큰 | 용도 | 현재 DS 상태 | 우선순위 |
|----------|------|-------------|---------|
| `--sidebar-width-default` | 사이드바 고정 너비 (e.g., 240px) | 없음 — Sizing 토큰 없음 | `P1` |
| `--sidebar-width-collapsed` | 사이드바 접힌 너비 (e.g., 56px) | 없음 | `P2` |
| `--topbar-height` | GNB 높이 (e.g., 56px) | 없음 | `P1` |
| `--camera-cell-min-width` | 카메라 그리드 셀 최소 너비 | 없음 — 그리드 패턴 전체 부재 | `P1` |
| `--camera-grid-gap` | 카메라 그리드 간격 | 없음 | `P1` |

**임시 대응:** 서비스 전용 CSS 커스텀 프로퍼티로 관리. DS 피드백 후 토큰화 여부 결정.

## 3. 컴포넌트 Gap

### 3-1. 영상 플레이어 관련

| 필요 컴포넌트 | 설명 | 현재 DS 상태 | 우선순위 |
|-------------|------|-------------|---------|
| VideoPlayer | 실시간·녹화 영상 재생 컨테이너 | 없음 — 영상 도메인 전용 | `P1` |
| CameraCell | 카메라 카드 (영상 + 오버레이 + 상태 배지) | 없음 | `P1` |
| CameraGrid | 2×2 / 4×4 등 그리드 레이아웃 | 없음 | `P1` |
| LiveBadge | "LIVE" 실시간 상태 표시 배지 | 없음 — DS에 Live 상태 개념 없음 | `P1` |
| VideoTimeline | 녹화 구간 탐색 타임라인 슬라이더 | 없음 | `P2` |
| VideoControls | 재생/정지/음소거/다운로드 컨트롤 바 | 없음 | `P2` |

**처리 방향:** 모두 service-specific 컴포넌트로 설계. DS 기반 토큰(color, radius, spacing)만 참조.

---

### 3-2. 상태 표시

| 필요 컴포넌트 | 설명 | 현재 DS 상태 | 우선순위 |
|-------------|------|-------------|---------|
| EmptyState | 데이터 없음 / 검색 결과 없음 | 없음 | `P1` |
| LoadingSpinner | 로딩 중 상태 | 없음 | `P1` |
| ErrorState | 오류 상태 페이지 / 인라인 오류 | 없음 | `P2` |
| SkeletonLoader | 콘텐츠 로딩 중 뼈대 UI | 없음 | `P3` |

**임시 대응:** 서비스 전용으로 구현. 색상은 `--color-status-*` + `--color-text-*` 참조.

---

### 3-3. 피드백 / 알림

| 필요 컴포넌트 | 설명 | 현재 DS 상태 | 우선순위 |
|-------------|------|-------------|---------|
| Toast / Snackbar | 출동 요청 완료, 설정 저장 등 단기 알림 | 없음 | `P1` |
| Modal / Dialog | 확인 다이얼로그, 폼 다이얼로그 | 구조 토큰(`--radius-modal-md`, `--color-surface-raised`)만 있음. 컴포넌트 미등록. | `P1` |
| Alert Banner | 인라인 경고 / 정보 배너 | 없음 | `P2` |

**임시 대응:**  
- Toast: 서비스 전용 구현. `--color-surface-raised` + `--color-status-*` + `--radius-card-md` 참조.  
- Modal: 구조 토큰 활용, 서비스 전용 컴포넌트로 구현.

---

### 3-4. 내비게이션

| 필요 컴포넌트 | 설명 | 현재 DS 상태 | 우선순위 |
|-------------|------|-------------|---------|
| Sidebar / Nav | 전체 앱 좌측 내비게이션 | `in-progress` — 착수 전 확인 필요 | `P1` |
| Tab | 설정 화면 등의 탭 패턴 | 별도 Tab 컴포넌트 없음 | `P2` |
| Breadcrumb | 사이트 > 카메라 등 계층 탐색 | 없음 | `P3` |

**임시 대응:**  
- Sidebar: Nav 컴포넌트 in-progress 상태 모니터링. 착수 전 구조 공유 필요.  
- Tab: Button (active/default 조합) 또는 Radio로 임시 구현 가능.

---

### 3-5. 영상 검색 전용

| 필요 컴포넌트 | 설명 | 현재 DS 상태 | 우선순위 |
|-------------|------|-------------|---------|

| VideoSearchResultCard | 검색 결과 영상 카드 (썸네일 + 타임스탬프 + 하이라이팅) | 없음 | `P1` |

**처리 방향:** SearchBar는 Input 확장. 나머지는 service-specific 설계.

## 5. Gap → DS 피드백 제출 목록

> DS 개선 요청으로 올릴 후보 항목. 클라우드 영상 전용은 제외하고, 범용성 있는 것만 선별.

| 항목 | 유형 | 피드백 내용 |
|------|------|-----------|
| EmptyState | 컴포넌트 신규 | 데이터 없음 상태 컴포넌트 필요 |
| Toast / Snackbar | 컴포넌트 신규 | 단기 피드백 알림 컴포넌트 필요 |
| Modal / Dialog | 컴포넌트 신규 | 구조 토큰은 있으나 컴포넌트 미등록 |
| LoadingSpinner | 컴포넌트 신규 | 로딩 상태 컴포넌트 없음 |
| Tab | 컴포넌트 신규 | 설정·상세 화면에서 범용 패턴 |
| Sidebar 너비 토큰 | 토큰 신규 | Sizing 카테고리에 sidebar-width 토큰 필요 |
| AI 이벤트 색상 alias | 토큰 신규 | status-* 외 이벤트 유형별 semantic 색상 필요 |
