S1 서비스 통합 에이전트 → 에이전트 팀 구성
전체 현황
통합 에이전트가 어떤 서비스를 분석하고 있고, 어떤 항목이 검토를 기다리는지 한눈에 확인합니다.
에이전트 팀 구성
통합 에이전트 조직 구성을 확인합니다. 각 역할이 어떤 상태인지, 어떤 서비스를 담당하는지 볼 수 있습니다.
에이전트 활동보고서
정의된 에이전트들이 실제 프로젝트에서 어떻게 활용되고 있는지 확인합니다. 현재 파일 기준 진단이며, 호출 로그가 아닌 산출물과 프롬프트 정의를 근거로 판단합니다.
공유 자료
통합 에이전트를 만들면서 그룹원들과 나누고 싶은 자료, 생각, 이야기를 자유롭게 올리는 공간입니다.
서비스 분석 현황
서비스별로 분석이 어디까지 진행됐는지 확인합니다. 현재 보고 있는 화면, 다음 할 일, 검토 대기 항목을 한눈에 볼 수 있습니다.
통합 UVIS
이동체서비스 — SAMSUNG 통근버스 관제 시스템 UVIS 분석 현황 및 작업 공간 연결 상태를 확인합니다.
관계사용 UVIS - User
이동체서비스 — 관계사용 UVIS 사용자 앱 분석 준비 현황을 확인합니다.
관계사용 UVIS - Admin
이동체서비스 — 관계사용 UVIS 관리자 앱 분석 준비 현황을 확인합니다.
SVMS
영상서비스 — SW(Thick Client) 기반 레거시 영상관제 시스템 분석 준비 현황을 확인합니다.
클라우드영상시스템
영상서비스 — 클라우드 기반 영상 관제 시스템 분석 준비 현황을 확인합니다.
클라우드매니저
출입관리서비스 — 클라우드 기반 출입관리 시스템 분석 준비 현황을 확인합니다.
빌딩매니저
빌딩관리서비스 — 빌딩 관리 통합 시스템 분석 준비 현황을 확인합니다.
